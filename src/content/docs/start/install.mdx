<Aside>
	supervise is invite-only for now. Its repository is private: you need an
	invitation to it on GitHub, accepted, and an SSH key your GitHub account
	knows.
</Aside>

## What you need first

- **Claude Code**: `claude`, run once and logged in.
- **uv**, with its tool bin directory on `PATH` (`uv tool update-shell`).
- **git**.

Everything else the installer supplies, [repld](https://github.com/angelsen/repld)
included.

## Install

<Steps>

1. Clone the repository you were invited to, over SSH, and enter it.

   ```bash
   git clone <the SSH URL from your invitation> supervise && cd supervise
   ```

2. Run the installer. It reads its own directory, so it is never piped from a
   URL.

   ```bash
   ./install.sh
   ```

   It installs repld when it is missing and registers it with Claude Code as
   an MCP server, installs `supervise` into uv's tool bin, adds the Claude
   Code plugin, and runs `supervise doctor`. At a
   terminal it then offers, once, to store your own seat-view key.

3. Read doctor's lines. Each `missing` or `degraded` line prints its own fix.
   [Doctor](/start/doctor/) explains each state.

4. Check that Claude Code sees repld and the plugin.

   ```bash
   claude mcp list       # repld must say Connected
   claude plugin list    # supervise@supervise
   ```

   The installer registers repld for your user when Claude Code has no
   server of that name, and leaves an existing one alone. A seat refuses to
   start where repld is not registered. To register it for one project
   only:

   ```bash
   claude mcp add --scope local repld -- repld bridge
   ```

</Steps>

To upgrade, pull and run `./install.sh` again.

## Uninstall

The plugin goes first, so that no hook calls a `supervise` that is gone.

```bash
claude plugin uninstall supervise@supervise
claude plugin marketplace remove supervise
uv tool uninstall supervise
```
